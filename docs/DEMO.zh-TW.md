## 影片中的九個步驟

錄影使用英文介面，下列時間為約略的場景起點。可暫停或拖曳進度，搭配[圖解操作指南](USAGE.zh-TW.md)練習。

| 時間 | 步驟 | 怎麼操作 |
| --- | --- | --- |
| 00:00 | 認識工作台 | 左側看原始 PDF，右側對照檢索證據與模型回答。 |
| 00:04 | 1. 上傳文件 | 點 **Upload PDF**，選擇 CC0 範例，等待 **Indexed**。本次錄影重用既有索引。 |
| 00:09 | 2. 詢問文件內容 | 輸入「What is the maximum upload size for the Cedar pilot?」，點 **Retrieve & answer**。查看檢索片段與真實模型回答。 |
| 00:14 | 3. 點擊引用查證 | 點答案下方來源，跳到第 2 頁，核對原始表格的 **30 MB**。 |
| 00:21 | 4. 檢查解析 | 開啟 **Parsed content**，對照解析表格、片段 ID 與來源頁碼。來源框線是內容區塊範圍，不是精確文字位置。 |
| 00:26 | 5. 查看執行設定 | 展開 **Run settings & prompt**，檢查 prompt、模型、檢索設定與各階段實測耗時。 |
| 00:31 | 6. 測試無法回答的問題 | 詢問「What is the pilot's annual electricity cost in dollars?」。文件無法確認年度電費；保存的回答表達無法確認，且沒有引用。 |
| 00:37 | 7. 重新查看歷史 | 開啟 **Run history**，選擇已保存的問題，重新查看答案、證據與設定。 |
| 00:42 | 8. 清理 PDF | 開啟 **Document library**，搜尋並勾選範例後點 **Delete selected**，閱讀永久刪除範圍再確認。歷史仍保留，缺少原檔的頁面連結停用。 |
| 00:53 | 9. 清空紀錄 | 開啟 **Run history → Clear all → Delete permanently**。確認筆數與範圍；執行紀錄和 PDF 分開清理。 |
| 01:02 | 換你試試 | 依[快速啟動](../README.zh-TW.md#快速啟動)，使用公開範例的[六個問題](../examples/questions.json)，連接自己的模型服務操作。 |

## 操作目前的功能

先依[快速啟動](../README.zh-TW.md#快速啟動)啟動目前應用。下列使用繁體中文介面名稱，語言選擇在重新整理後保留。可使用虛構 CC0 PDF 練習；Cedar 規格是範例文件內容，不代表應用當前設定。

1. **檢查並處理上傳。** 選擇原生文字 PDF 前先看**上傳限制**，預設每份 30 MB／200 頁，沒有總字數上限。查看**正在檢查 PDF… → 正在上傳 PDF…**，接著是等待／解析／切塊／向量化／索引階段。已索引片段數是取得確認的寫入量，不是解析完成百分比。重複文件會重用索引；新 PDF 或**重新索引**才會執行處理。**停止處理**保留原檔，等目前操作安全結束；**重新索引**則從完整流程重來。
2. **追蹤或停止問答。** 詢問第 2 頁的上傳容量問題，查看階段與已等待秒數，並檢查陸續顯示的證據。按**停止查詢**後保留已取消紀錄，不提供最終答案；重新送出會建立新的執行。關閉瀏覽器分頁不會停止伺服器工作。
3. **閱讀來源並運用答案。** 點第 2 頁引用，在 PDF 搜尋欄輸入 `30 MB`，調整縮放並選取原生文字。使用**複製答案與來源**、**下載 Markdown**或**下載執行 JSON**。來源框線與搜尋亮顯用途不同，兩者都不保證每句模型回答正確。
4. **依執行控制生成。** 展開**模型生成參數**，試用**精確表達**（`T=0、P=1`），或在顯示範圍內調整 Temperature／Top-P／輸出 token 上限。再次提問，從歷史重開並檢查保存的數值。低 Temperature 不保證 JSON 格式或事實正確。
5. **說明 context 與錯誤恢復。** 在 **Context 與模型呼叫** 對照**估算輸入**、**輸入預算**、**輸出保留**、納入／排除片段，再與實際回報輸入／輸出 token 比較。原始排除片段仍可檢查，但模型不能引用。展開呼叫嘗試查看 prompt、結果與耗時；有需要時才會出現重試／修正，不是每次都有。未完整回報的用量是未知，token 計數不是金額帳單。次數上限見[有限次錯誤恢復](WORKFLOWS.zh-TW.md#有限次錯誤恢復)，估算方式見[Context 與 token](WORKFLOWS.zh-TW.md#context-與-token)。
6. **摘要全文。** 按**三點文件摘要**，查看**文件摘要步驟**：map 批次涵蓋全部已保存片段，筆記超出預算時才有 reduce 節點，final 產生三點或拒答。點來源按鈕核對姓名、日期、金額及要求的行動。保存／重開流程紀錄，需要時可按**停止查詢**。Top-K 不限制摘要來源，涵蓋所有輸入不代表壓縮後保留全部事實。
7. **檢查檢索選擇。** 開啟**檢索選項 → 檢索模式**，切換向量、關鍵字 · BM25、混合 · RRF。比較證據卡標示的分數與**檢索排名追蹤**；最終 Top K 與各方法候選數分開，cosine 門檻不會過濾 BM25／RRF。用[八頁文件與中英文案例](RETRIEVAL.zh-TW.md)練習、點引用並重開歷史以恢復模式。
8. **比較固定條件的修改。** 範例 PDF 已索引後，依[評測指令](WORKFLOWS.zh-TW.md#可重複評測)執行同一組 12 題中英文題目。固定文件／解析／切塊／embedding／檢索／prompt，一次改一項生成參數。查看來源頁召回率／MRR、引用覆蓋、預期文字、拒答、耗時及已回報／未知 token。比較檢索模式時，依 [16 題固定條件評測](RETRIEVAL.zh-TW.md#一次比較一個條件)固定生成與其餘檢索設定。評測使用 CLI；這些小型檢查不是語意準確率。

面試時可搭配[問題與實作對照表](WORKFLOWS.zh-TW.md#面試題與專案對照)，將保存的執行紀錄與 PDF 一起展示。[流程里程碑](MILESTONE.zh-TW.md)另有真實驗證紀錄；那些結果並非這段影片的新場景。

## 錄影與字幕來源

已發布教學從應用提交 `7e16f9b` 錄製，呈現當時的清理介面，包含**兩次真實模型查詢**及暫存工作空間的實際 PDF／歷史刪除。中英文影片正常速度播放，實際片長 84.7 秒；在此錄影上渲染字幕不會新增模型查詢，也無法展示原畫面沒有的控制項。錄影沒有測量 GPU 效能，CC0 Cedar 範例是虛構資料，與你的正常工作空間分開。刪除影響見[清理指南](CLEANUP.zh-TW.md)。

- [繁體中文字幕文字](media/ragglass-demo.zh-TW.vtt)：與影片相同的步驟標題、操作指令與提示。

修改字幕或錄製新影片，請依[素材重現步驟](LAUNCH.zh-TW.md#重現影片與封面)。頁內播放器由 GitHub 提供，其他 Markdown 檢視器可能只顯示網址。繁體中文教學使用英文介面搭配繁體中文操作字幕；應用本身提供可持久保存的語言切換。

功能改動時，同步更新中英文 README、本指南的涵蓋範圍／目前操作及相關功能指南。字幕操作必須對應錄影畫面。影片要展示新功能時，需重新錄製並同步雙語字幕／來源紀錄及已發布嵌入 metadata；完成前保留錄製版本，明示哪些控制項尚未拍入。
