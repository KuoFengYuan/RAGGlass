# 跟著影片教學操作

[English](DEMO.md) | **繁體中文**

[直接在 README 播放繁體中文教學](../README.zh-TW.md#觀看操作示範)。教學字幕已嵌入影片，不需要開啟字幕選項或另外下載。每個畫面都有步驟編號、操作按鈕與檢查重點。字幕位於工作台下方，並保留播放器控制列的空間。

## 九個操作步驟

錄影使用英文介面，下列時間為約略的場景起點。可暫停或拖曳進度，搭配[圖解操作指南](USAGE.zh-TW.md)練習。

| 時間 | 步驟 | 怎麼操作 |
| --- | --- | --- |
| 00:00 | 認識工作台 | 左側看原始 PDF，右側對照檢索證據與模型回答。 |
| 00:04 | 1. 上傳文件 | 點 **Upload PDF**，選擇 CC0 範例，等待 **Indexed**。本次錄影重用既有索引。 |
| 00:09 | 2. 詢問文件內容 | 輸入「What is the maximum upload size for the Cedar pilot?」，點 **Retrieve & answer**。查看檢索片段與真實模型回答。 |
| 00:14 | 3. 點擊引用查證 | 點答案下方來源，跳到第 2 頁，核對原始表格的 **30 MB**。 |
| 00:21 | 4. 檢查解析 | 開啟 **Parsed content**，對照解析表格、片段 ID 與來源頁碼。來源框線是內容區塊範圍，不是精確文字位置。 |
| 00:26 | 5. 查看執行設定 | 展開 **Run settings & prompt**，檢查 prompt、模型、檢索設定與各階段實測耗時。 |
| 00:31 | 6. 測試無法回答的問題 | 詢問「What is the pilot's annual electricity cost in dollars?」。文件無法確認年度電費；保存的回答表達無法確認，且沒有引用。 |
| 00:37 | 7. 重新查看歷史 | 開啟 **Run history**，選擇已保存的問題，重新查看答案、證據與設定。 |
| 00:42 | 8. 清理 PDF | 開啟 **Document library**，搜尋並勾選範例後點 **Delete selected**，閱讀永久刪除範圍再確認。歷史仍保留，缺少原檔的頁面連結停用。 |
| 00:53 | 9. 清空紀錄 | 開啟 **Run history → Clear all → Delete permanently**。確認筆數與範圍；執行紀錄和 PDF 分開清理。 |
| 01:02 | 換你試試 | 依[快速啟動](../README.zh-TW.md#快速啟動)，使用公開範例的[六個問題](../examples/questions.json)，連接自己的模型服務操作。 |

## 錄影與字幕來源

本次教學從應用提交 `7e16f9b` 重新錄製，呈現最新清理介面，包含**兩次新真實模型查詢**及暫存工作空間的實際 PDF／歷史刪除。中英文影片正常速度播放，實際片長 84.7 秒；在此錄影上渲染字幕不會再新增模型查詢。錄影沒有測量 GPU 效能，CC0 Cedar 範例是虛構資料，與你的正常工作空間分開。刪除影響見[清理指南](CLEANUP.zh-TW.md)。

- [目前錄製來源紀錄](media/demo-recording.json)：文件 hash、真實模型答案、引用與實測問答耗時。

修改字幕或錄製新影片，請依[素材重現步驟](LAUNCH.zh-TW.md#重現影片與封面)。頁內播放器由 GitHub 提供，其他 Markdown 檢視器可能只顯示網址。繁體中文教學使用英文介面搭配繁體中文操作字幕；應用本身提供可持久保存的語言切換。
