## 影片中的二十個步驟

影片主要使用英文介面，另有一段繁體中文語言保存示範。時間為四捨五入的場景起點。可暫停或拖曳進度，搭配[圖解操作指南](USAGE.zh-TW.md)練習。

| 時間 | 步驟 | 操作與檢查重點 |
| --- | --- | --- |
| 00:00 | RAGGlass．看見 RAG 的內部 | 從上傳、檢索證據到回答，一起對照原始 PDF。 最新介面實錄，真實本機推論；文件皆為虛構 CC0 範例。 |
| 00:04 | 1．上傳與處理進度 | 點 Upload PDF，查看檢查、解析與索引進度。 空白工作區實際建立新索引；只處理原生文字，未啟用 OCR。 |
| 00:18 | 2．設定生成參數 | 展開 Generation options，調整溫度、Top-P 與輸出上限。 每次執行保存設定；低溫度仍不保證事實或 JSON 正確。 |
| 00:24 | 3．以向量檢索提問 | 詢問上傳容量，點 Retrieve & answer，追蹤查詢進度。 實際執行 E5、Qdrant 與模型推論，沒有預先寫好的答案。 |
| 00:30 | 4．點引用核對原文 | 點第 2 頁來源，在原始表格核對 30 MB。 引用 ID 有效不代表每一句語意都正確，仍需查證原文。 |
| 00:36 | 5．搜尋與縮放 PDF | 搜尋 30 MB，將 PDF zoom 調整為 125%。 原生文字可搜尋與選取；來源框線不是精確文字邊界。 |
| 00:43 | 6．檢查解析片段 | 開啟 Parsed content，找到容量上限的解析表格。 對照文字、片段 ID 與來源頁碼，追查答案的資料來源。 |
| 00:48 | 7．中文關鍵字檢索 | 上傳檢索範例，選 Keyword，詢問紀錄保存期限。 BM25 不產生查詢 embedding；cosine 門檻停用。 |
| 01:00 | 8．查證中文原文 | 點第 6 頁引用，在 PDF 搜尋「九十天」。 PDF.js 使用本機字元映射，顯示與搜尋原生中文字。 |
| 01:07 | 9．混合向量與關鍵字檢索 | 選 Hybrid，Top K 3、候選 20，詢問 CEDAR-X17。 RRF 合併排名；cosine 門檻只過濾向量分支。 |
| 01:14 | 10．檢查兩路候選排名 | 展開 Retrieval rankings，對照分數與納入的來源。 cosine、BM25、RRF 尺度不同，分數不是答案正確機率。 |
| 01:22 | 11．估算與實際 Token 用量 | 查看 Context & model calls 的預算與模型實際用量。 UTF-8 事前估算不等於模型分詞；未知用量也不是零。 |
| 01:29 | 12．複製與匯出證據 | 複製答案與來源，再下載 Markdown 報告。 實際匯出保留混合設定與各路分數，方便分享和重現。 |
| 01:34 | 13．全文三點摘要 | 選回 field guide，點 Summarize document in 3 points。 真實摘要涵蓋保存的片段，每個重點必須附有效來源。 |
| 01:48 | 14．檢查摘要節點 | 展開 Document summary steps，查看來源與 prompt。 實際執行 map／final；筆記超過預算時才需要 reduce。 |
| 01:54 | 15．停止執行中的摘要 | 再次啟動摘要，在生成期間點 Stop query。 取消紀錄保留已取得的證據，不顯示最終答案。 |
| 02:01 | 16．測試文件無法回答的題目 | 詢問年度電費，查看不帶引用的拒答結果。 範例文件沒有這項費用，不能以其他知識補出答案。 |
| 02:09 | 17．還原混合檢索紀錄 | 開啟 Run history，重開 CEDAR-X17 的問題。 還原原文件、混合模式與候選深度，重新檢查來源。 |
| 02:17 | 18．持久保存語言選擇 | 切換繁體中文，重新整理後確認語言仍保留。 介面語言不會自動翻譯已保存的模型答案。 |
| 02:22 | 19．獨立刪除 PDF | 在 Document library 勾選檢索範例，確認刪除所選。 歷史與證據文字保留，已移除原檔的頁面連結停用。 |
| 02:34 | 20．清空執行紀錄 | 開啟 Run history，選 Clear all，確認清理範圍。 保留另一份 field guide 與索引；PDF 和歷史分開管理。 |
| 02:42 | 換你試試．重現與評測 | 試用兩份 CC0 文件，再用 CLI 比較固定條件的檢索。 雙語指南另有系統限制與 16 題評測；影片未展示完整評測。 |

## 操作目前的功能

先依[快速啟動](../README.zh-TW.md#快速啟動)啟動目前應用。下列使用繁體中文介面名稱，語言選擇在重新整理後保留。可使用虛構 CC0 PDF 練習；Cedar 規格是範例文件內容，不代表應用當前設定。

1. **檢查並處理上傳。** 選擇原生文字 PDF 前先看**上傳限制**，預設每份 30 MB／200 頁，沒有總字數上限。查看**正在檢查 PDF… → 正在上傳 PDF…**，接著是等待／解析／切塊／向量化／索引階段。已索引片段數是取得確認的寫入量，不是解析完成百分比。重複文件會重用索引；新 PDF 或**重新索引**才會執行處理。**停止處理**保留原檔，等目前操作安全結束；**重新索引**則從完整流程重來。
2. **追蹤或停止問答。** 詢問第 2 頁的上傳容量問題，查看階段與已等待秒數，並檢查陸續顯示的證據。按**停止查詢**後保留已取消紀錄，不提供最終答案；重新送出會建立新的執行。關閉瀏覽器分頁不會停止伺服器工作。
3. **閱讀來源並運用答案。** 點第 2 頁引用，在 PDF 搜尋欄輸入 `30 MB`，調整縮放並選取原生文字。使用**複製答案與來源**、**下載 Markdown**或**下載執行 JSON**。來源框線與搜尋亮顯用途不同，兩者都不保證每句模型回答正確。
4. **依執行控制生成。** 展開**模型生成參數**，試用**精確表達**（`T=0、P=1`），或在顯示範圍內調整 Temperature／Top-P／輸出 token 上限。再次提問，從歷史重開並檢查保存的數值。低 Temperature 不保證 JSON 格式或事實正確。
5. **說明 context 與錯誤恢復。** 在 **Context 與模型呼叫** 對照**估算輸入**、**輸入預算**、**輸出保留**、納入／排除片段，再與實際回報輸入／輸出 token 比較。原始排除片段仍可檢查，但模型不能引用。展開呼叫嘗試查看 prompt、結果與耗時；有需要時才會出現重試／修正，不是每次都有。未完整回報的用量是未知，token 計數不是金額帳單。次數上限見[有限次錯誤恢復](WORKFLOWS.zh-TW.md#有限次錯誤恢復)，估算方式見[Context 與 token](WORKFLOWS.zh-TW.md#context-與-token)。
6. **摘要全文。** 按**三點文件摘要**，查看**文件摘要步驟**：map 批次涵蓋全部已保存片段，筆記超出預算時才有 reduce 節點，final 產生三點或拒答。點來源按鈕核對姓名、日期、金額及要求的行動。保存／重開流程紀錄，需要時可按**停止查詢**。Top-K 不限制摘要來源，涵蓋所有輸入不代表壓縮後保留全部事實。
7. **檢查檢索選擇。** 開啟**檢索選項 → 檢索模式**，切換向量、關鍵字 · BM25、混合 · RRF。比較證據卡標示的分數與**檢索排名追蹤**；最終 Top K 與各方法候選數分開，cosine 門檻不會過濾 BM25／RRF。用[八頁文件與中英文案例](RETRIEVAL.zh-TW.md)練習、點引用並重開歷史以恢復模式。
8. **比較固定條件的修改。** 範例 PDF 已索引後，依[評測指令](WORKFLOWS.zh-TW.md#可重複評測)執行同一組 12 題中英文題目。固定文件／解析／切塊／embedding／檢索／prompt，一次改一項生成參數。查看來源頁召回率／MRR、引用覆蓋、預期文字、拒答、耗時及已回報／未知 token。比較檢索模式時，依 [16 題固定條件評測](RETRIEVAL.zh-TW.md#一次比較一個條件)固定生成與其餘檢索設定。評測使用 CLI；這些小型檢查不是語意準確率。

面試時可搭配[問題與實作對照表](WORKFLOWS.zh-TW.md#面試題與專案對照)，將保存的執行紀錄與 PDF 一起展示。[流程里程碑](MILESTONE.zh-TW.md)另有真實驗證紀錄；那些結果並非這段影片的新場景。

## 錄影與字幕來源

教學使用應用提交 `7855a83`，在自有暫存工作區正常速度錄製，包含**四次真實模型問答**、**一次完成的三點摘要**（map／final），及**一次在生成階段取消的摘要**。中英文影片均為 168.4 秒。兩份公開 PDF 重新解析、向量化並索引；之後獨立刪除 lab、保留其歷史，再清空歷史並保留 field guide。重製字幕不新增模型查詢。小型範例不需要 reduce 層；刻意觸發恢復錯誤與完整 CLI 評測未錄製。錄影沒有測量 GPU 效能，兩份 CC0 文件都是虛構資料，與原有正常工作區分開。刪除影響見[清理指南](CLEANUP.zh-TW.md)。

修改字幕或錄製新影片，請依[素材重現步驟](LAUNCH.zh-TW.md#重現影片與封面)。頁內播放器由 GitHub 提供，其他 Markdown 檢視器可能只顯示網址。中英文教學共用實錄、各自嵌入同語言字幕；畫面主要為英文，並示範切換繁體中文及重新整理後保存。

功能改動時，同步更新中英文 README、本指南的涵蓋範圍／目前操作及相關功能指南。字幕操作必須對應錄影畫面。影片要展示新功能時，需重新錄製並同步雙語字幕／來源紀錄及已發布嵌入 metadata；完成前保留錄製版本，明示哪些控制項尚未拍入。
