# 跟著影片教學操作

[English](DEMO.md) | **繁體中文**

[直接在 README 播放繁體中文教學](../README.zh-TW.md#觀看操作示範)。教學字幕已嵌入影片，不需要開啟字幕選項或另外下載。每個畫面都有步驟編號、操作按鈕與檢查重點。字幕位於工作台下方，並保留播放器控制列的空間。

## 七個操作步驟

錄影使用英文介面，下列時間為約略的場景起點。可暫停或拖曳進度，搭配[圖解操作指南](USAGE.zh-TW.md)練習。

| 時間 | 步驟 | 怎麼操作 |
| --- | --- | --- |
| 00:00 | 認識工作台 | 左側看原始 PDF，右側對照檢索證據與模型回答。 |
| 00:04 | 1. 上傳文件 | 點 **Upload PDF**，選擇 CC0 範例，等待 **Indexed**。本次錄影重用既有索引。 |
| 00:09 | 2. 詢問文件內容 | 輸入「What is the maximum upload size for the Cedar pilot?」，點 **Retrieve & answer**。查看檢索片段與真實模型回答。 |
| 00:18 | 3. 點擊引用查證 | 點答案下方來源，跳到第 2 頁，核對原始表格的 **30 MB**。 |
| 00:26 | 4. 檢查解析 | 開啟 **Parsed content**，對照解析表格、片段 ID 與來源頁碼。來源框線是內容區塊範圍，不是精確文字位置。 |
| 00:31 | 5. 查看執行設定 | 展開 **Run settings & prompt**，檢查 prompt、模型、檢索設定與各階段實測耗時。 |
| 00:36 | 6. 測試無法回答的問題 | 詢問「What is the pilot's annual electricity cost in dollars?」。文件無法確認年度電費；保存的回答表達無法確認，且沒有引用。 |
| 00:42 | 7. 重新查看歷史 | 開啟 **Run history**，選擇已保存的問題，重新查看答案、證據與設定。 |
| 00:47 | 換你試試 | 依[快速啟動](../README.zh-TW.md#快速啟動)，使用公開範例的[六個問題](../examples/questions.json)，連接自己的模型服務操作。 |

## 錄影與字幕來源

本次教學沿用原始真實推論影片，以正常速度播放，只重製教學字幕與字幕背景區。此次編輯**沒有新增模型查詢**，保留原始答案與問答耗時，也沒有測量 GPU 效能。CC0 範例中的 Cedar 試用方案是虛構資料。

- [原始錄製來源紀錄](media/demo-recording.json)：文件 hash、真實模型答案、引用與實測問答耗時。
- [教學字幕來源](media/demo-tutorial.json)：完整英文與繁體中文步驟內容。
- [重製紀錄](media/demo-tutorial-render.json)：來源／重製程式雜湊、實際片長、尺寸與影片檔案雜湊。
- [繁體中文字幕文字](media/ragglass-demo.zh-TW.vtt)：與影片相同的步驟標題、操作指令與提示。

修改字幕或錄製新影片，請依[素材重現步驟](LAUNCH.zh-TW.md#重現影片與封面)。頁內播放器由 GitHub 提供，其他 Markdown 檢視器可能只顯示網址。繁體中文教學使用英文介面搭配繁體中文操作字幕；應用本身提供可持久保存的語言切換。
