# Original PDF fixture

**English** | [繁體中文](README.zh-TW.md)

`ragglass-field-guide.pdf` is an original three-page, native-text PDF with a simple configuration table. It describes a fictional Cedar pilot. Its specifications are invented test data, never measured performance. The generator is `scripts/make_sample.py`; regenerate with `.venv/bin/python scripts/make_sample.py`.

Both this fixture and its generator are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No third-party material is embedded. `questions.json` contains six questions with expected evidence pages, including an unanswerable question. Upload the PDF before asking these questions; all displayed answers are generated by your configured model, not precomputed demo answers.

`evaluation-cases.json` extends these annotations to twelve English/Chinese cases and records the PDF hash, gold pages, answerability and expected text variants. These annotations are also CC0. The evaluation reports page recall and literal text matches, not semantic entailment or production accuracy. See [workflow evaluation](../docs/WORKFLOWS.md).

`scripts/verify_workflows.py` generates a separate six-page, fictional native-text support complaint inside disposable storage. Nora Lin, order CL-204, the amounts and dates are invented CC0 test data. The complaint text and generator are also dedicated to CC0; the generated PDF and full traces remain in ignored temporary storage, not a private upload or a committed document.
